Reference pose: zero (pose the real robot like this)

How to use (torque off, move the robot by hand):
  1. First put the robot in the zero pose (legs straight, head straight, the same as during calibration) and set "Reference" to Zero: all joints should be close to 0°.
  2. One joint at a time: click it in the table and see in the third image which way its positive direction turns. Then turn that joint on the real robot by hand the same way. The model in the first two images should turn the same way, and the reading should go up.
  3. Put the robot in the standing pose (home) and set "Reference" to home: the differences should be within a few degrees, and body pitch / roll should be close to 0.
Calibration: if a direction is wrong, click Reverse on that row (it takes effect at once; move the joint again to check). Put the joint in the zero pose, then click Set selected joint to zero (or pose the whole body and click Set all to zero). You can also calibrate in the standing pose: set "Reference" to Standing home, and with torque off put the robot in the standing pose on the table (feet flat, body level: the IMU pitch / roll below ≈0). The buttons change to Set ... to standing angle: they save the current pose as the home angles (for example hip pitch −26.2°), not as 0°. Fine-tune while standing in home: the −/+ on each side of the zero value make this joint, for the same command angle, actually turn 0.5° more in the negative/positive direction (see the positive direction in the third image). Then click Write and go home to see the result (restarting robotd keeps the torque on). The mouth has no model: opening the mouth should make the reading go up; close it fully and set it to zero. Changed values are shown in orange. They are saved on the robot only when you click Write config (a backup is made first).
Colors: difference <3° green, <8° yellow, otherwise red.
